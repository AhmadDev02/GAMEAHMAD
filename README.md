# GAMEAHMAD

Arcade & Game Engine Suite built with Python and `pygame-ce`.

## 🎮 Features
- **Dashboard Launcher Hub (`main.py`)**: Antarmuka modern dan interaktif untuk memilih dan meluncurkan game.
- **Ping Pong AI (`pingpong_game.py`)**: Permainan arcade ping pong klasik dengan mode AI dan efek visual neon/cyberpunk.
- **Chess Game & AI Engine (`chess_gui.py` & `chess_engine.py`)**: Permainan catur lengkap dengan GUI interaktif dan evaluasi mesin AI catur.

## 🚀 Cara Menjalankan

### 1. Prasyarat & Instalasi
Pastikan Python 3 sudah terinstal, lalu instal dependensi:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Menjalankan Dashboard Game
```bash
python main.py
```

Atau jalankan game secara langsung:
- **Ping Pong AI**: `python pingpong_game.py`
- **Catur (Chess)**: `python chess_gui.py`
